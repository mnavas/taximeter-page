# taximeter-page

Marketing landing page and documentation site for **Taximeter** — the self-hosted taxi dispatch,
metering, and fleet-monitoring platform.

Static HTML, no build step. Spanish, served via GitHub Pages.

- `index.html` — landing page
- `pages/` — documentation (install, daily-use, fleet-fares, admin)
- `assets/` — shared stylesheet and images

The product itself lives at [mnavas/taximeter](https://github.com/mnavas/taximeter).
